# Windows Compatibility Todo

Quarterdeck's Windows code-remediation backlog is complete as of 2026-08-29. Windows remains labeled experimental until the committed tree passes the required native CI job and the real-provider acceptance matrix below. This file is the release ledger; the evidence and commands are in the [support audit](./windows-support-audit.md) and [native validation guide](./windows-native-smoke.md).

## Completed remediation sequence

- [x] **1. Make graceful shutdown Windows-safe.** Parent disconnects enter the idempotent runtime shutdown controller directly. Development, dogfood, integration, Playwright, and Agent Lab supervisors close the runtime's dedicated stdin control pipe instead of relying on a programmatic Windows `SIGTERM`; console close, Ctrl+C, Ctrl+Break, duplicate-signal suppression, bounded cleanup, and tree-kill fallback have explicit platform policy.
- [x] **2. Make child-process launch portable.** Shared owners launch npm's absolute JavaScript entrypoint through the absolute Node executable, resolve `.cmd`/`.bat`/`.com`/`.exe`/`.ps1` commands to an exact inherited-`PATH` target before entering a project cwd, use absolute trusted System32 executables, merge Windows environment keys case-insensitively, avoid shell parsing where argv execution is possible, and terminate timed-out command trees instead of only their shim process.
- [x] **3. Require native Windows validation.** The reusable test workflow has a non-optional `windows-latest` job for clean root/web installs, production build, packaged CLI startup, the complete root gate (including focused native integration), and web tests. The focused command is `npm run test:windows-smoke` after a build.
- [x] **4. Verify ConPTY lifecycle behavior.** Native coverage starts deterministic task and `cmd.exe` shell PTYs, submits Windows carriage-return input, observes a provider hook, exercises forced same-size resize through a bounded ConPTY row nudge, disconnects and reconnects control/IO sockets, restores exact geometry and viewport state, stops both sessions, and proves ownership records retire.
- [x] **5. Scope process cleanup to exact Quarterdeck launches.** A Windows task PTY is not handed off until a protected launch record contains the exact runtime/root PID plus CIM creation identities and proves the root is still the runtime's direct child. Startup and shutdown revalidate those identities and signal only exact owned roots; malformed, live-owner, missing, unrelated, reused, or unverifiable records fail closed. Name and command-line heuristics were removed.
- [x] **6. Enforce private diagnostic and lab storage.** Sensitive directories receive a protected inheritable DACL granting full control only to the current user and LocalSystem before the first content write. Runtime descriptors/tokens, journals, bundles, Agent Lab state/evidence, staged credentials, browser state, and custom output roots share that boundary; Windows ACL failure cannot fall through to broadly inherited persistence.
- [x] **7. Harden diagnostic names and redaction.** Provider-derived bundle names, image names, project IDs, run IDs, alternate data stream syntax, device names, control characters, trailing dots/spaces, post-truncation edge cases, and Windows paths containing spaces are handled without unsafe filenames or content leakage.
- [x] **8. Make worktree and filesystem behavior deterministic.** Ignored directories use junctions; denied file symlinks fall back to exclusive task-local copies; failures are typed rather than silent. Recursive deletion retries transient Windows sharing violations, atomic writes avoid meaningless POSIX mode options on Windows, locked files retain exact ownership, and workdir/provider-history reads remain bounded on a validated handle while pre/post-open canonical and file identities defend junction/symlink races.
- [x] **9. Preserve Git fidelity.** Path-bearing status, diff, conflict, and file-list flows use NUL-delimited parsing; leading-space names survive; case-only renames work on case-insensitive filesystems; every runtime and Agent Lab Git subprocess uses its exact inherited-`PATH` executable; Windows test repositories disable `core.autocrlf`; Git commands opt into `core.longpaths=true`; and native smoke checks a tracked path longer than 260 characters.
- [x] **10. Normalize path identity across runtime and browser state.** Server and UI comparisons account for Windows separators and case folding without rewriting displayed Git paths or trimming valid POSIX whitespace. Project index aliases, task identities, board reconciliation, metadata stores, query equality, managed-worktree containment, folder/project launch, drive-root worktree labels, and injected platform tests use platform-correct path semantics.
- [x] **11. Harden hook and status-line transport.** Claude hooks, Codex hooks, and Claude's optional status line use one platform command owner. Windows invokes absolute system PowerShell with a fixed encoded bootstrap and direct Win32 argv serialization, bypassing current-directory/`PATH` decoys and preserving spaces, multiline arguments, `%`, `!`, `^`, `&`, `|`, parentheses, stdin, and stdout.
- [x] **12. Make build, package, and test fixtures Windows-native.** Build chmod is POSIX-only; Agent Lab emits `.cmd`/PowerShell launchers, owns Windows process trees, and derives Git's common metadata directory without launching a checkout-local executable; filesystem tests use directory junctions instead of privileged file symlinks; POSIX mode assertions are platform-gated; expected paths use the selected path implementation; and fake command/Git environments are case-aware and line-ending-stable.

## Native acceptance gate

- [ ] **Required CI evidence.** Push or open a pull request for the committed feature branch and confirm the non-optional `Windows native` job passes from a clean checkout for that exact commit.
- [ ] **Real-provider acceptance.** On a normal, non-administrator Windows account, exercise authenticated supported Claude Code, Codex, and pinned Pi installations through new task, input/approval, stop, exact resume, restart, reconnect/restore, same-size redraw, runtime restart, and crash-orphan recovery. Confirm actual IDE/folder opening and that diagnostic exports remain inaccessible to a second local account.

Do not remove the README's experimental label until both acceptance items pass. Failures found there return to the completed sequence as concrete regressions with automated coverage before the gate is rerun.
